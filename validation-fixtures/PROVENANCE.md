# Fixture provenance

Created during the IBM Bob 2.0 event on 2026-09-25 by **Codex**, as an independent validation contribution. These original synthetic packages contain no personal/customer data, copied project, runtime dependencies or lifecycle scripts. They have never been published to npm.

These files are **not evidence of IBM Bob usage**. The PackProof runner and its substantive Bob IDE implementation are outside this folder. A manual Node/npm baseline can evaluate these contracts independently of that runner.

The `labels-missing-template` and `labels-fixed` code/resources must remain byte-identical; only the package.json `files` allowlist differs. `labels-broken-export` has the fixed file list and deliberately points its public export to a missing file. `tally` independently uses CommonJS, a different entrypoint and a JSON resource.

Contracts are explicit reference expectations, not autogenerated assertions from observed output. `label-wrong-expectation.mjs` intentionally fails on the correct library. `label-import-only.mjs` intentionally does not cover the resource-backed operation and therefore can pass on a broken archive. These controls must remain visibly distinct from a functional success.
